# Creative Portfolio Website

A clean, responsive portfolio template for a video editor and graphic designer. Built with plain HTML, CSS and JavaScript.

## 1. Open the website
1. Extract `creative_portfolio.zip`.
2. Open the `creative_portfolio` folder.
3. Double-click `index.html` to preview it in your browser.
4. For a better editing experience, open the folder in Visual Studio Code.

## 2. Add your photo
- Put your portrait in `assets/images/`.
- Name it `profile.jpg` (or change the image path in `index.html`).
- JPG and PNG images are supported.

## 3. Add your videos
- Put your MP4 videos in `assets/videos/`.
- Use these filenames, or change the filenames in `index.html`:
  - `video-1.mp4`
  - `video-2.mp4`
  - `video-3.mp4`
- Optional video preview images can be added as `video-poster-1.jpg` and `video-poster-2.jpg` in `assets/images/`.

## 4. Add graphic design samples
Add JPG or PNG images to `assets/images/` with these names, or edit the matching image paths in `index.html`:
- `design-1.jpg`
- `design-2.jpg`
- `design-3.jpg`
- `design-4.jpg`

## 5. Personalize the text and links
Open `index.html` and search for:
- `YOUR NAME` / `Your Name` — replace with your name.
- `BASED IN YOUR CITY` — replace with your city, or remove it.
- `youremail@example.com` — replace with your email address.
- Social profile URLs — replace with your own links.
- Project titles and descriptions — replace with your project details.

## 6. Change the design
Open `style.css`. The main colors are at the top inside `:root`. You can change the colors, fonts, spacing and layout there.

## Folder structure
```
creative_portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    └── videos/
```

The media folders are intentionally empty so you can add your own JPG/PNG photos and MP4 videos. The site does not upload files to a server; the media files must be included in the website folder when you publish it.
